Server-Sent Events (SSE) client with namespaces, rooms and replay — reconnects resume via
Last-Event-ID from a bounded server-side message window instead of losing messages.
Includes a demino-mountable reference server implementing the same protocol and a Redis
fan-out adapter (npm + JSR; demino an optional peer). The client uses the global
EventSource: browsers, Deno, and Node 22+ with --experimental-eventsource.
